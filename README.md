# Expert Marketplace

Маркетплейс независимых экспертов: почасовые консультации и услуги с фиксированной стоимостью.

## Архитектура MVP

- Next.js 14, TypeScript, Tailwind CSS
- Supabase (PostgreSQL, Auth, Row Level Security)
- Бронирования, заказы, платежи и отзывы
- Монетизация: комиссия с каждой успешной сделки (проектная ставка 12%)

## Статус

Репозиторий инициализирован. Код приложения и миграции ещё необходимо перенести из подготовленного архива; Supabase и платежи пока не подключены. Не используйте этот репозиторий как готовый production-сервис.

## Следующие шаги

1. Перенести исходники из архива `expertly-marketplace-backend.zip` в корень репозитория.
2. Подключить проект Supabase, применить SQL-миграции по порядку.
3. Настроить `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` в окружении размещения (не коммитить секреты).
4. Перевести демо-формы на реальные запросы к базе, настроить платёжные webhooks и публикацию.
